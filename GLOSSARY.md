# Formless

A general-purpose agent harness that boots with a fixed set of built-in tools and builds every other capability it needs for any use case, rather than specialising in coding. It is centred on a daemon core that user interfaces connect to.

## Language

**Formless**:
A general-purpose agent harness that starts from a fixed set of built-in tools and builds the tools it needs for the task at hand.
_Avoid_: Coding agent, form library, chatbot

**Built-in Tool**:
A tool the daemon implements itself, always present: the registry primitives (`create_tool`, `find_tools`, `read_tool`, `test_tool`, `run_script`, …), the Pending Invocation handles, metrics and artifact reads, and the MCP, skills, memory, planning and user-facing ones. Built-ins have no versions, are excluded from Self-Optimisation, cannot be retired, cannot be called from `run_script`, and hold no Capabilities of their own. SPEC §7.1 lists them.
_Avoid_: Native tool, system tool

**Bootstrap Tool**:
`create_tool`, the built-in that writes every other tool. It is immutable, never optimised, and cannot be retired or widened.
_Avoid_: Meta-tool, seed tool

**Tool**:
A persisted, versioned capability created with `create_tool`, with a name, description, input schema, and sandboxed script implementation.
_Avoid_: Plugin, extension, function

**Daemon Core**:
The long-lived local process that owns the agent loop, tools, sessions, and state, and that interfaces connect to.
_Avoid_: Server, backend, engine

**Tool Success Rate**:
The measured share of a tool's invocations that succeed, used as the primary signal for self-optimisation.
_Avoid_: Accuracy, score

**Self-Optimisation**:
The harness improving its own tools over time, driven by measured Tool Success Rate.
_Avoid_: Self-improvement, auto-tuning

**Session**:
One user's continuous conversation and task history with the harness, resumable after interruption. Many Sessions run concurrently against one Daemon Core.
_Avoid_: Thread, chat, connection

**Run**:
One unit of work inside a Session, started by a user message and continuing until the agent answers or the user interrupts it. Budgets and configured step limits can pause a Run.
_Avoid_: Task, job, turn

**Invocation**:
A single execution of one version of a Tool with one input. Invocations are recorded and measured for Tool Success Rate.
_Avoid_: Call, execution, request

**Steer**:
A user message sent while a Run is active that is injected into the Run at the next step boundary. In Formless, pressing Enter during a Run steers by default; queueing a message for after the Run is the alternate action.
_Avoid_: Interrupt, interjection

**Pending Invocation**:
An Invocation that has exceeded the soft time threshold (default 300s) without finishing. It keeps running in the background while the agent receives a handle to poll, await, or abandon it.
_Avoid_: Timed-out invocation, hung tool, background job

**Capability**:
A declared permission a Tool needs, such as network access or filesystem access to a path. A Tool can never exceed its declared Capabilities.
_Avoid_: Permission, scope

**Candidate**:
A proposed new version of a Tool, generated by Self-Optimisation and not yet promoted. A Candidate must beat the current version in sandboxed replay before promotion.
_Avoid_: Draft, patch

**Promotion**:
Replacing the current version of a Tool with a Candidate that measurably outperformed it in sandboxed replay. Every version is kept for rollback.
_Avoid_: Deploy, release

**Retired Tool**:
A Tool the agent has removed from the callable registry. Its versions and Invocation history are retained and it can be restored; only the user can permanently purge it.
_Avoid_: Deleted tool, disabled tool

**Compaction**:
Replacing older Session history and tool output with a persisted summary checkpoint so a Run can continue within the model's context window. Large tool outputs are kept in full as artifacts on disk.
_Avoid_: Truncation, summarisation

**Relay**:
A shipped WebSocket intermediary that a Daemon Core connects out to, so a browser frontend can reach the local daemon. Application payloads are encrypted end to end between the clients and daemon; the Relay routes ciphertext.
_Avoid_: Proxy, tunnel


**Role**:
A named model assignment with a description, Provider, model, optional fallbacks, and optional system addendum for sub-agents.
_Avoid_: Persona, agent type

**Provider**:
A named model endpoint and its connection settings and credential reference. Roles select models from Providers.
_Avoid_: Model, vendor

**Profile**:
An isolated set of Formless configuration, data, and daemon state selected with `--profile`.
_Avoid_: Account, workspace

**Skill**:
A named, reusable instruction document loaded into a Session, with optional supporting files. Skills guide the agent; they do not grant Capabilities.
_Avoid_: Tool, plugin

**MCP Server**:
An external Model Context Protocol process or HTTP endpoint whose tools Formless can expose through its MCP integration.
_Avoid_: Module, built-in Tool

**Memory**:
A persisted note the harness can recall across Runs, subject to the configured memory lifecycle and user controls.
_Avoid_: Session transcript, context window

**Proposal**:
A recorded suggested harness or memory change awaiting the applicable review or application path.
_Avoid_: Promotion, applied change

**Job**:
A persisted automation that starts Runs on a configured schedule and records its delivery and execution state.
_Avoid_: Run, Pending Invocation

**Artifact**:
A file retained by the daemon for a Session, including emitted files and full output too large for the transcript, addressable through an artifact handle.
_Avoid_: Attachment, Tool version
