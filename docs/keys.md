# Keys and commands

Generated by `formless docs --keys` from the tables `/help` shows; do not edit by hand. These are the main keys and every command. Footers show the shortcuts that fit. In Sessions, Tools, Metrics, Proposals and Search, press `?` outside filter editing for view keys.

## TUI keys

| Key | What it does |
|---|---|
| Enter | send, or steer the running Run |
| Ctrl+J / Ctrl+Enter / Alt+Enter | queue for after the Run |
| Esc | stop the Run / close a dialog (Vim Insert: enter Normal first) |
| Vim: i/a/I/A, Esc | enter Insert / return to Normal; mode shown in input border |
| Vim: w/b/e/0/$/gg/G, h/j/k/l | move within composer or Tool editor; list keys unchanged |
| Vim: d/c/y + motion or object | iw/aw, iW/aW, quotes, ()/[]/{}/<>; dd/cc/yy for lines |
| Vim: u | undo the previous edit in Normal mode |
| Vim: . / p / P | repeat last change / paste private yank register (no OS clipboard) |
| Vim Tool editor: Ctrl+S / Ctrl+Q | save / explicitly cancel; Esc keeps edited text |
| Tool editor: Ctrl+D, then h | check the edit, then review draft hunks; Ctrl+S still saves normally |
| Hunk review: n/p, a/r, u, c | next/previous, keep/reject, undo latest change, comment with server path:line |
| Ctrl+G | edit composer, instructions or Tool draft in $VISUAL/$EDITOR; normal send/save still applies |
| Ctrl+_ / Ctrl+Shift+_ / Alt+/ | undo / redo / redo in composer and Tool editor |
| Ctrl+U/K/W, Alt+D; Ctrl+Y, Alt+Y | kill text privately; yank, cycle previous kills |
| Shift+arrows/Home/End; Ctrl+Shift+C/X | select draft text; explicitly copy/cut selection |
| Tool editor Esc / Ctrl+Q in Vim | ask before discarding modified text; y discards, n/Esc keeps editing |
| Ctrl+C | clear the input; twice to detach |
| Tab / Shift+Tab | switch views |
| PgUp / PgDn | scroll the chat |
| PgUp / PgDn in a Settings form | scroll the form without changing the active field |
| [ ] | move Chat focus on empty input (non-Vim or Vim Normal) |
| Enter / F6 on focused Tool call | toggle preview / view full stored input and result |
| c / C / Esc on Chat focus | copy / copy as Markdown / leave focus |
| ↑ / ↓ (non-Vim composer) | move within wrapped draft rows; browse Session history at the first/last row, including empty/one-line input |
| j / k, g / G, Ctrl+D / Ctrl+U | move in list views (Sessions, Tools, Metrics, Proposals) |
| / | command palette (Tab completes) |
| @ | reference a file |
| ? | this help (on an empty input) |
| Shift+drag | select text (Option in iTerm2, Fn in Terminal.app) |

## Commands

Type `/` in the TUI or the web composer; the same commands work in both (a few are TUI-only).

### Session

| Command | What it does |
|---|---|
| `/new [TEMPLATE]` | start a new Session, optionally from a template |
| `/template save\|delete NAME [FIRST MESSAGE]` | save this Session's setup as a template, or delete one |
| `/templates` | list Session templates |
| `/export [json\|md\|html]` | export this Session: a re-importable bundle, or a readable transcript |
| `/pin` | pin or unpin this Session (P in Sessions) |
| `/tag [NAME…]` | tag this Session, or list tags (filter Sessions with /#tag) |
| `/untag NAME…` | remove tags from this Session |
| `/cd [PATH]` | show or change this Session's working directory |
| `/sessions` | list and switch Sessions (T toggles lineage tree) |
| `/fork` | fork the current Session |
| `/search` | search all Sessions |
| `/editor` | compose the current buffer in $VISUAL/$EDITOR (also Ctrl+G) |
| `/edit` | edit your last message and retry from there |
| `/retry [--model MODEL]` | re-run your last message, optionally on another model; the old answer stays in a fork |
| `/attach PATH` | attach a file to your next message |
| `/paste` | attach an image from the clipboard (also Ctrl+V) |
| `/open [ID]` | show a stored output full-screen |
| `/open link [N]` | open the Nth link in the last answer in your browser |
| `/open path FILE[:LINE]` | open a file the chat mentions in $EDITOR |
| `/copy [N \| code [N]]` | copy the last answer, the Nth message from the bottom, or a code block |
| `/usage` | tokens and cost of this Session |
| `/pager diagram [N]` | a Mermaid diagram at full size (←/→ scroll) |
| `/open diagram [N]` | open a Mermaid diagram's source in mermaid.live |
| `/pager code [N]` | open a code block unwrapped with line numbers (←/→ scroll) |
| `/table [N]` | open the last answer's Nth table full-width (←/→ scroll) |
| `/compact [FOCUS]` | summarise the Session now, keeping what FOCUS asks |
| `/rename [NAME\|auto]` | rename the Session; auto suggests a name from recent messages |
| `/instructions [TEXT\|clear]` | standing instructions for this Session's agent |
| `/context` | how full the context window is, and what fills it |
| `/undo [tool]` | undo the last Session delete; `tool`: the last Tool registry change |
| `/summarise-branch SOURCE_SESSION` | generate a branch summary for review, then insert one note here |
| `/compare SESSION_A SESSION_B` | compare stored branches and recorded usage (no model call) |

### Run control

| Command | What it does |
|---|---|
| `/stop` | stop the current Run (Esc) |
| `/cancel` | cancel the stalled or pending Tool call |
| `/resend` | re-send a stalled provider request |
| `/compare-models A B [prompt]` | the same prompt on two models, side by side with time and cost |
| `/step` | step mode: pause before each Tool call (Enter run, e edit, s skip) |
| `/good [comment]` | rate the last answer 👍 (feeds Run metrics and routing) |
| `/bad [comment]` | rate the last answer 👎 (feeds Run metrics and routing) |
| `/unrate` | clear your rating of the last answer |
| `/recap` | expand or fold the last long Run's "What I did" |
| `/review [RUN_ID]` | review file hunks: keep, reject, undo or comment |
| `/files` | the files the last Run changed, with diffs |
| `/rewind [PATH]` | put the last Run's file changes back (one file, or all) |
| `/queue [edit\|rm\|up\|down N]` | the messages queued for after this Run: edit, remove or reorder them |
| `/limit N\|off` | cap the current (or next) Run at N steps; it pauses there |
| `/resume` | continue an interrupted or paused Run |
| `/abandon` | drop an interrupted or paused Run |
| `/details` | show the last provider error in full |
| `/approve` | list approvals waiting for you |
| `/invocations` | list pending Invocations |
| `/kill HANDLE` | cancel a pending Invocation |
| `/drop HANDLE` | stop waiting for a pending Invocation |
| `/agents [N]` | list sub-agents, or show one's transcript |
| `/thinking` | show or hide model thinking |

### Tools

| Command | What it does |
|---|---|
| `/tools` | open the Tools view |
| `/tool NAME` | open a Tool's detail in the Tools view |
| `/modules` | list shared modules |
| `/module NAME [edit\|rollback N\|delete]` | open a shared module: code, versions, Tools using it |
| `/tooloff NAME` | switch a Tool off for the agent, or back on (not a retirement) |
| `/toolpin NAME` | pin or unpin a Tool: pinned Tools are always listed to the agent |
| `/tooltag NAME [TAG…]` | set a Tool's tags (none clears them); filter the Tools view with #tag |
| `/metrics` | open the Metrics view |
| `/proposals` | open the prompt Proposals view |
| `/propose` | generate a measured prompt proposal |
| `/revoke TOOL [CAPABILITY] \| all [FAMILY]` | revoke a Tool's granted Capabilities, or every grant (of a family) |
| `/approvals [FAMILY]` | every approval: Tool, Capability, scope, when, by whom, last used |
| `/audit [FILTER]` | show the audit log |
| `/descriptionreviews` | retained description warnings and before/after changes |
| `/security` | what the daemon can reach: grants, denials, trusted folders, MCP, hooks, relay, web |

### Settings

| Command | What it does |
|---|---|

| `/timestamps` | show or hide message times and day separators |
| `/settings` | open the Settings view |
| `/model [ID]` | pick the model and effort (fuzzy search) |

| `/pull MODEL` | Ollama: download a model |

### Integrations

| Command | What it does |
|---|---|
| `/mcp` | list MCP servers |
| `/mcp restart NAME` | restart an MCP server |
| `/mcp log NAME` | an MCP server's stderr log |
| `/mcp tools NAME` | an MCP server's tools, on or off, with token cost |
| `/mcp tool NAME TOOL on\|off` | turn one MCP tool on or off |
| `/mcp catalog` | popular MCP servers you can add |
| `/mcp add ID [key=value]` | add a server from the catalog |
| `/mcp import [NAME]` | servers configured in Claude Desktop, Cursor or VS Code |
| `/mcp: SERVER:PROMPT [ARGS]` | send an MCP prompt as your message |
| `/prompts` | list MCP prompts |
| `/prompt SERVER:NAME [KEY=VALUE …]` | insert an MCP prompt |
| `/skills [NAME]` | list Skills, or preview one |
| `/skill: NAME [ARGS]` | load a Skill into this Session |
| `/skills enable NAME` | enable a Skill |
| `/skills disable NAME` | disable a Skill |
| `/memory` | list saved memories |
| `/remember TEXT` | save a preference or fact as a memory |
| `/forget TEXT` | find memories mentioning TEXT; the same again deletes them |
| `/memory edit ID TEXT` | change a memory |
| `/memory rm ID` | delete a memory |
| `/memory on ID` | use a memory again |
| `/memory off ID` | stop using a memory |
| `/memory used` | memories reportedly carried by the latest Run |
| `/jobs [enable\|disable\|run\|history\|rm ID]` | list scheduled jobs, or act on one |
| `/jobs enable ID` | enable (approve) a job |
| `/jobs disable ID` | pause a job |
| `/jobs rm ID` | delete a job |

### App

| Command | What it does |
|---|---|
| `/status` | the daemon: memory, CPU, database, running work |
| `/storage` | disk used by Sessions, artifacts, logs, backups |
| `/gc [run]` | what clean-up would free; `run` frees it |
| `/backup` | back up the database now |
| `/docs [topic] [--text]` | open an online guide; terminal --text reads this build's bundled Markdown |
| `/setup` | the setup wizard again: re-enter the API key, or change provider |
| `/tour [skip]` | a 2-minute guided first task; `skip` hides the offer |
| `/notes` | every note so far, in the pager |
| `/vim [on\|off]` | toggle persistent Vim editing in composer and Tool editor |
| `/help` | all commands and keys (also ? on an empty input) |
| `/restart-daemon` | restart the daemon (e.g. after an upgrade); waits for no Run to be going |
| `/quit` | quit the TUI (the daemon keeps running) |
